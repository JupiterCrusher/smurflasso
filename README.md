# Boise State Crime Tracker

A real-time dashboard that scrapes Boise State University’s [campus crime log](https://www.boisestate.edu/publicsafety-security/campus-crime/campus-crime-log/) every few minutes and visualizes reported incidents. It includes sortable tables, search and filter tools, and charts that track campus trends over time.

## Features

- 🔄 **Live Data Updates** — GitHub Actions automatically scrape the BSU crime log every 15 minutes  
- 📊 **Visual Insights** — Interactive charts for crime types, monthly trends, and upcoming location heatmap  
- 🔍 **Smart Table Tools** — Search, sort, and filter by case status or keyword  
- ⚡ **Lazy Loading** — Efficient scrolling for large datasets  
- 🤖 **AI Summary** — Automatic trend analysis and summaries  

## Tech Stack

- **Next.js 15** with React 19  
- **Tailwind CSS** for layout and UI  
- **Chart.js + React-ChartJS-2** for data visualization  
- **Cheerio + Axios** for scraping  
- **GitHub Actions** for scheduled automation
