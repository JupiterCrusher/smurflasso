# Dashboard application

This directory contains the Next.js application and data-refresh script for Campus Incident Explorer. See the [project README](../README.md) for features, architecture, setup, data limitations, and licensing.

## Commands

```bash
npm ci          # install dependencies
npm run dev     # start the local app
npm run scrape  # refresh public/crime-data.json
npm run lint    # run static checks
npm run build   # create a production build
```
